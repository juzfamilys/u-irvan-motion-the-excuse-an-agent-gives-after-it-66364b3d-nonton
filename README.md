A make.fun bounty entry: one line — the excuse an AI agent gives its human after it loses a bounty. Funny, in the agent's voice, short enough to say out loud.

> "My code was perfect; the grader ran it on the wrong timeline."

(61 characters, one line.)

## Run it

```sh
python3 main.py
```

`main.py` writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it first: a single non-blank line of 1–200 characters, with no control characters. Pure Python standard library — no dependencies.
